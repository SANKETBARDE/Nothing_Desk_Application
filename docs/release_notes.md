# Nothing Desk — MVP Release Notes (v1.0.0)

### Highlights
- **Nothing OS Visual Language:** Monochromatic black surfaces, subtle dot-matrix wallpapers, frosted glassmorphism, and iconic Nothing red accents.
- **Window Management Engine:** Floating, draggable, resizable windows with 8-direction handles, titlebar pointer capture, deterministic z-index focus, and snap zones (half-screen split & top maximize).
- **Start Menu & Application Launcher:** Multi-column application grid featuring priority apps on top (Phone, Messages, Chrome, Camera, Settings, Files) and instant keyboard search.
- **Windows-Inspired Shortcut Engine:** Centralized shortcut dispatcher with input protection (`Meta`, `Ctrl+Space`, `Meta+D`, `Alt+Tab`, `Alt+F4`, `Meta+E`, `Meta+I`, `Esc`).
- **Scoped Storage Access Framework:** Safe, local file viewer with no broad storage permission demands.
- **Capacitor & Kotlin Native Bridge:** Native `AppLauncherPlugin`, `StorageBridgePlugin`, `DisplayDetectPlugin`, and `DesktopPresentation` surface support.
- **Safe State Recovery & Persistence:** Atomic schema-migrated local storage and global error boundary preventing shell crashes.
